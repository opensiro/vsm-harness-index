# Analytics

Deterministic aggregate views over the canonical VSM Harness Index corpus.

The canonical analytical sources remain:

- `assessments/*.md` for standalone assessment state and metadata;
- `data/catalog.psv` for catalog provenance and repository creation time;
- `data/reassessment-history.psv` for reassessment events.

Generated views in this directory are projections, not a second assessment database. Do not hand-maintain ownership classifications or aggregate counts here.

## Views

- [`ownership.md`](ownership.md) — detailed ownership-state mix and collapsed material-path categories by VSM function.
- [`organizational-forms.md`](organizational-forms.md) — autonomous-coverage distribution and complete ownership-vector frequencies.
- [`cooccurrence.md`](cooccurrence.md) — material-path and autonomous 6×6 function co-occurrence matrices.
- [`reassessments.md`](reassessments.md) — changed-function, outcome, and Methodology-version reassessment aggregates.
- [`temporal.md`](temporal.md) — year/quarter autonomous-ownership projections.

The non-temporal corpus pivots are generated by:

```bash
python scripts/render_analytics.py
python scripts/render_analytics.py --check
```

## Semantics

Ownership states are categorical arrangements, not a maturity or product-quality ladder.

- `A(P)` and `C(P)` remain distinct in detailed ownership tables.
- `A(P)` collapses to base `A` only in explicitly labelled autonomous-coverage projections, matching existing ranking semantics.
- `C(P)` collapses to Constructor only in explicitly labelled material-path projections.
- `?` (unknown) remains distinct from `—` (no established path).
- No weighted or fractional score is assigned to `C`, `P`, `—`, or `?`.

## Temporal convention

Temporal analytics use one primary cohort date:

```text
data/catalog.psv:repository_created_at
```

`Period` means the **GitHub repository creation period**.

For example, `2026-Q3` means that the repository itself was created on GitHub between July and September 2026. It does **not** mean that the harness was released, assessed, last updated, or that a particular VSM function was implemented during that quarter.

Year and quarter are derived from `repository_created_at`; they are not maintained as separate catalog fields.

The Index snapshot date is machine-readable provenance stored in `data/metrics.json`. It is not another cohort axis and is not shown as a separate analytics view.
