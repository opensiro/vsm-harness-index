# ChatDev

## Review boundary

## Repository architecture
ChatDev is a zero-code multi-agent orchestration platform. Users define agents, workflows and tasks; the project history also documents central orchestrators that activate/sequence agents and communicative role collaboration.

## Primary evidence
- `README.md`: customizable multi-agent systems, configured agents/workflows/tasks, historical central-orchestrator and collaboration patterns, and explicit branch boundaries.
