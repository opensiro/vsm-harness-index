# RepoMaster

## Review boundary
RepoMaster at the pinned revision as the repository-discovery/execution agent system and its specialized backend agents.

## Repository architecture
RepoMaster analyzes tasks, discovers relevant GitHub repositories/tools, configures and executes them. The CLI advertises intelligent multi-agent orchestration and specialized deep-search/general-assistant/repository-agent backends.

## Primary evidence
- `README.md`: autonomous discovery/configuration/execution pipeline; multi-agent orchestration mode; specialized agent backends.

## Operational model
Specialized agents can perform S1 work. The high-level orchestration evidence does not specify whether agents mutually adjust/conflict-dampen or are merely routed by task type.
