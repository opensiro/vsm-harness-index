# AutoGPT

## Review boundary
AutoGPT repository at the pinned revision, focusing on its open-source builder and agent runtime rather than vendor-operated infrastructure as an organization.

## Repository architecture
The platform builds, deploys and runs agents as visual block workflows. Agents execute complete workflows on demand, schedules or triggers; the builder exposes branching/connected blocks while the run surfaces show agent runs, costs and actions needing attention.

## Primary evidence
- `README.md`: open-source agent platform; visual builder; complete workflows; schedules/triggers; managed vs self-hosted runtime boundary.

## Operational model
An executing AutoGPT agent/workflow is the S1. Visual blocks, schedules and triggers structure that operation, but deterministic graph composition is not a separate autonomous coordination function.

## S1 — Operations
`A`: agent runs execute outcome-oriented workflows and make bounded model/tool decisions within them. Confidence: high.

## S2 — Coordination
`—`: no material first-party evidence reviewed here establishes anti-oscillation among multiple autonomous S1 units; workflow branching/sequencing alone does not qualify.
