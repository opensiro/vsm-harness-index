Vercel and DeepAgents adapters run the package contract; Codex agent capability uses a distinct provider-managed boundary. Children are bounded read-only research tasks. A fresh refutation pass can use runtime checks against proposed documents; certification remains adjacent verification rather than an operational owner. Public maintainers control package releases, not embedded-user identity decisions.
