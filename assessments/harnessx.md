## Repository architecture

`HarnessConfig` owns instantiated provider, tools, process hooks, workspace, sandbox and run policy; public `Harness.run` assembles or restores state and enters source-owned `run_loop`. The agent model can return registered tool calls; tool registry executes them, `ToolResultEvent` is appended to the conversation and observed by the next model step. The `RunLoop` also records trajectories/observations, budget failures and task boundaries. This code establishes a supported S1 current operating cycle, without crediting any hypothetical external model provider's unrelated organizational rights. `MetaAgent` is a *distinct shipped model-runner* that reads prior task trajectories, writes a proposed changed `config.yaml` and associated processor/template edits under configured write roots, then calls `EvolveValidator.run`. ## Operational model

Current agent requests run as model/tool/feedback S1 work; actual task trajectories and benchmark outcomes feed a **different across-round decision** about what the agent harness should become for future tasks. At the improvement-process recursion, a model-driven meta-agent edits a candidate future configuration, first-party validator accepts only viable proposals, and the first-party round controller installs/promotes a validated successor that is then executed and assessed. This is a bounded S4 future-capability path, not necessarily an independent quality/audit or legitimate organizational purpose authority. The baseline executor, model vendors and external benchmark grading policy are not all one viable subsystem.

## S1 — Operations

- State: A
- Function: Conduct current user/evaluation task work by selecting available tools through the task agent and adapting next model actions after real tool execution observations.
- Disturbance / variety regulated: New task/environment inputs, failing or successful real tools, edits/observations, unexpected model answers, session interruptions and capability budgets.
- Decisive decision or feedback right: The configured model produces tool calls and subsequent decisions; source-owned RunLoop executes registered tool callbacks and inserts real results into task state/conversation; this changes next possible actions and the produced task result.
- Decision owner: First-party HarnessX installed model-backed task agent using third-party inference through an explicit provider boundary. Tool registry/hooks and model budgets limit discretionary task actions.
- Supporting / enforcement mechanisms: HarnessConfig, RunLoop, tool registry and ToolResultEvent, state/trajectory, hook processors, workspace and sandbox, cost guard and interruption/resume.
- Closure path: Task → Harness.run → model-driven RunLoop → selected registered tool call → executable handler → ToolResultEvent appended to state → next model turn/action/final deliverable → task trajectory, used by evolution.
- Boundary reachability: Shipped public `Harness.run` and provider configuration lead directly to `run_loop` with actual tool registry execution and observation persistence. This is source-level production code, not just an interface or benchmark score.
- Why this is / is not agent-owned: Tool choice and subsequent result-informed task continuation belong to the configured model-backed agent; process hooks and static restrictions are safeguards and do not stand in for autonomous task decisions.
- Evidence: [harnessx/core/harness.py](https://github.com/Darwin-Agent/HarnessX/blob/915520584c92cc35ed24aef1af17eec1d60c0b01/harnessx/core/harness.py#L969); [harnessx/core/harness.py](https://github.com/Darwin-Agent/HarnessX/blob/915520584c92cc35ed24aef1af17eec1d60c0b01/harnessx/core/harness.py#L1066); [harnessx/core/runloop.py](https://github.com/Darwin-Agent/HarnessX/blob/915520584c92cc35ed24aef1af17eec1d60c0b01/harnessx/core/runloop.py#L116); [harnessx/core/runloop.py](https://github.com/Darwin-Agent/HarnessX/blob/915520584c92cc35ed24aef1af17eec1d60c0b01/harnessx/core/runloop.py#L415); [harnessx/core/runloop.py](https://github.com/Darwin-Agent/HarnessX/blob/915520584c92cc35ed24aef1af17eec1d60c0b01/harnessx/core/runloop.py#L489); [harnessx/core/runloop.py](https://github.com/Darwin-Agent/HarnessX/blob/915520584c92cc35ed24aef1af17eec1d60c0b01/harnessx/core/runloop.py#L550); [harnessx/core/runloop.py](https://github.com/Darwin-Agent/HarnessX/blob/915520584c92cc35ed24aef1af17eec1d60c0b01/harnessx/core/runloop.py#L581).
